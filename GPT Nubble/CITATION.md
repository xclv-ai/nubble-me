# Citing Nubble

Use a versioned repository commit or release when citing the current methods manuscript. No DOI, peer-review status, or named scientific author list has been assigned.

Suggested project citation:

> Nubble project contributors. 2026. *Beyond the Summary: Nubble and the So-What Layer: Evidence-linked, context-dependent decision support under limited attention*. Working methods paper, version 0.3. Repository: xclv-ai/nubble-me, `GPT Nubble/`. Include the exact commit used.

This is a project-level citation for the current release, not a claim of journal publication or individual authorship. The individual author list and affiliations should be supplied before manuscript submission. Cite underlying research independently; [paper/references.bib](paper/references.bib) and [paper/REFERENCES.md](paper/REFERENCES.md) contain verified metadata and source links.
