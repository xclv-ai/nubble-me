# Benchmarks — Apple Design Awards 2026 iPhone winners/finalists (screens studied 2026-10-14)

Sheet: `benchmarks/ada-2026-iphone-screens.jpg` (App Store screenshots). Source list: Apple Newsroom, 2 Jun 2026.

| App | Award | What it does that Nubble must learn |
|---|---|---|
| Tide Guide | Winner, Visuals & Graphics | The data IS the screen: one curve fills the phone, the current value huge ("3.8′ Rising Tide"), times as small labels on the curve. One atmosphere colour (ocean-blue gradient). |
| The Outsiders | Finalist, Interaction | One hero metric (96% Prime Readiness) + one plain sentence interpreting it ("All metrics agree: you're ready for action"); below, small tiles each with a number + a sparkline. Black + one neon accent. |
| Harvee | Finalist, Social Impact | A soft 3D character on the home; metric tiles each with a number AND a status word + coloured dot ("7,834 · Ok", "Insufficient" in red); headline promise "Data designed for clarity, not stress". |
| Moonlitt | Winner, Interaction | A 3D object you hold and turn (the moon); one deep colour world; months as a grid of small pictures, not text. |
| Not Boring Camera | Finalist | The controls ARE tactile 3D objects (a chunky physical camera with real-looking buttons) — the owner's "buttons as physical objects", done well. |
| grug | Winner, Delight & Fun | Radical restraint: one hand drawing, three short lines, a whole screen of space; personality in the voice. |
| Structured | Finalist | A timeline you read in one glance: coloured icons on a vertical line, time on the left. |

## The five rules they share (to apply to Nubble)
1. **One hero number per screen, with one sentence that says what it means.** Never a paragraph first.
2. **The chart is the screen.** The visual fills the space; text labels sit on it, small.
3. **Small tiles = number + status word + colour dot.** Readable in a second; red only for bad.
4. **One signature object/character in real 3D**, touched or tilted — the rest of the UI stays calm.
5. **One atmosphere colour per app, one accent.** Generous space. Nothing boxed for the sake of boxing.
